# load_scores — 성적 CSV 읽기 프로그램

## ① 무엇을 하나요 (What)

성적 CSV를 읽어 유효한 점수는 `kept`로, 건너뛴 줄은 이유와 함께 `skipped`로 나누어 돌려줍니다.

## ② 왜 만들었나요 (Why)

(여기는 직접 쓰세요. 두세 문장으로, 어떤 문제가 있어서 이 프로그램이 필요했는지 적습니다.
예: 실제 성적 파일에는 빈 칸 · 범위 밖 점수 · 중복 이름이 섞여 있어, 그냥 읽으면 프로그램이 죽거나 틀린 값이 섞이기 때문입니다.)

## ③ 어떻게 쓰나요 (How)

```bash
# 설치 (Python 3.8 이상, 별도 설치 없음)

# 실행
python load_scores.py scores.csv
```

CSV는 첫 줄이 헤더이고, 이후 `이름,점수` 한 줄이 한 사람입니다.
